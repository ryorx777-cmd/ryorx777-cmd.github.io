プライバシーポリシー

対象: 課題・計画管理ワーカー(以下「本アプリ」)。最終更新日: 2026年10月2日。

1. 利用者

本アプリは、開発者本人が自分のGoogleアカウントで使うための個人用のツールです。ほかの人には提供しておらず、ほかの人のデータは扱いません。

2. 取得する情報

  • Gmail(読み取り専用): 本人が特定のラベルを付けたお知らせメールの件名、本文、受信日時、メールID。
  • Google Classroom(読み取り専用): 本人が受講している授業、課題と締切、お知らせ、資料(添付されたGoogleドライブのファイルの名前とリンク)、本人の提出状況。
  • Googleカレンダー: 本アプリが作成したカレンダーとその予定だけ。ほかのカレンダーは読み書きしません。

3. 使い方

取得した情報は、本人の授業予定・課題・お知らせを本人のNotionのワークスペースにまとめ、本人のカレンダーに予定として表示するためだけに使います。広告や販売、分析のためには使いません。

4. 保存と共有

  • 取得した情報は、本人が管理するNotionのワークスペースと、本人の自宅のコンピューター(本アプリを動かす機器)に保存します。
  • Googleの認証情報(トークン)は、本アプリを動かす機器の中にだけ保存し、外部に送りません。
  • 取得した情報を第三者に提供、販売、共有しません。

5. Google API Services User Data Policy

本アプリによるGoogle APIから受け取った情報の利用と他のアプリへの転送は、Limited Use(限定的使用)の要件を含む Google API Services User Data Policy に従います。

6. アクセスの取り消しと削除

本アプリへのアクセスは、Googleアカウントのサードパーティ製アプリの管理ページ からいつでも取り消せます。取り消した後は、本アプリは新しい情報を取得しません。保存済みの情報は、本人がNotionと本アプリを動かす機器から削除します。

7. 問い合わせ

問い合わせ先は、Googleの同意画面に表示されるサポート用メールアドレスです。

English summary

Kadai Planner Worker is a personal tool used only by its developer with the developer's own Google accounts. It reads (read-only) the developer's labeled Gmail notices and Google Classroom data, and reads and writes only a calendar that the app itself creates. The data is stored only in the developer's own Notion workspace and on the developer's own device, is used only to organize the developer's own coursework, and is never sold or shared with third parties. Tokens stay on the device. The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: the support email shown on the Google consent screen.
